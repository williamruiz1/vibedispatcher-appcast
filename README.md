# vibedispatcher-appcast

Sparkle appcast feed hosting for [VibeDispatcher](https://github.com/williamruiz1/vibedispatcher).

The appcast is served via GitHub Pages at:
- https://williamruiz1.github.io/vibedispatcher-appcast/appcast.xml

Updated by `scripts/release.sh` in the VibeDispatcher repo on each release cut.
